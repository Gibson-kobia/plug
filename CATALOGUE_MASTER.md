## 04. PRODUCT MODELS (Template + Rules)

**Each product model entry must follow this structured format in future seed files. Do NOT add actual models until admin provides data. Leave TODO.**

Standard Product Model Record (TS interface — corresponds to DDL `products + product_variants`):

```typescript
interface ProductModelSeed {
  category_slug: string;           // C01..C13
  subcategory_slugs: string[];     // e.g. ['android-phones','midrange-phones']
  brand: string;                   // MUST match §03
  model_name: string;              // e.g. "Spark 20 Pro+"
  model_code?: string;             // e.g. "KJ7"
  release_year?: number;           // e.g. 2024
  slug: string;                    // URL-safe: "tecno-spark-20-pro-plus"
  seo_title: string;               // (from §09 SEO Names)
  seo_description: string;         // 155-160 chars, Kenyan context
  summary: string;                 // 1-2 line marketing blurb
  description_markdown: string;    // Long-form with bullet features
  warranty_months_default: number; // 12 / 24 / etc
  variants: ProductVariantSeed[];
  spec_values: Record<string, string | number | string[]>; // keyed by §05 spec keys
  accessory_compatibility_slugs?: string[]; // e.g. phone-case-iphone-15
  status: ProductStatus;           // §11
}

interface ProductVariantSeed {
  sku: string;                     // UNIQUE format: BRAND-MODEL-COLOR-STORAGE e.g. TEC-SP20P-BLK-256
  attributes_jsonb: Record<string, string>; // e.g. { color: "Midnight Black", storage: "256GB", ram: "8GB" }
  price_delta_kes?: number;        // add to base product.price — default 0
  compare_at_price_kes?: number;
  stock: number;                   // TODO — do NOT invent
  weight_grams?: number;
  gtin_ean_upc?: string;
  mpn?: string;
}
```

**Kenyan SKU convention:** `<3-letter brand>-<4-char model abbr>-<3-char color>-<3-char storage>`. Examples: `APC-IP15-BLK-128`, `SAM-S24U-GRN-512`, `TEC-SP20P-BLU-256`.

**Rule:** NEVER add a Product Model row without an admin-supplied source (price list, official spec sheet, distributor catalog). Leave TODO until then.
